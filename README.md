# 🍱 Food Rescue Network

## 📌 About the Project

Food Rescue Network is a smart donation and distribution management system developed using Python, Streamlit and SQLite.

The system helps donors provide food, clothes and other useful items to people in need. A delivery person collects the donated items from the donor and distributes them to the recipient.

## 🎯 Objective

The main objective of this project is to make the donation process simple, organized and easy to track.

## ✨ Features

- 👤 Donor Registration
- 🎁 Food Donation
- 👕 Clothes Donation
- 📦 Other Useful Item Donation
- 🚚 Delivery Person Registration
- 🔄 Delivery Person Assignment
- 📍 Donation Tracking
- 🤝 Distribution Management
- 📊 Admin Dashboard
- 📈 Donation Status and Category Statistics
- 🤖 Smart Donation Assistant
- 🗄️ SQLite Database

## 🔄 Working Process

1. Donor registers in the system.
2. Donor registers the item for donation.
3. A delivery person is registered.
4. The delivery person is assigned to the donation.
5. The donation is picked up from the donor.
6. The donation status can be tracked.
7. The donation is distributed to a person in need.
8. The status is updated to **DELIVERED**.

## 🛠️ Technologies Used

- Python
